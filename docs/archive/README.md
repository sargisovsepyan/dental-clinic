# Historical engineering reports

These documents preserve implementation, audit, corrective-pass, and release-readiness evidence from earlier development stages. They are intentionally archived rather than deleted because they record useful design decisions and verification work.

Historical reports may mention old branch names, phase labels, test totals, deployment plans, or capabilities that were accurate at the time. They are not the current product or operations contract. For current behavior, use the parent [documentation index](../README.md), the [OpenAPI contract](../openapi.yaml), and the current source tree.
